# Code of conduct

Be kind and be useful. Assume good faith, keep criticism about the work and not the person, and do not harass, demean or exclude anyone. Do not post other people's private information.

Maintainers may edit, hide or remove comments, issues and pull requests that break these rules, and may block repeat offenders. To report a problem, open an issue that says only that you have a conduct report and asks for a private way to send it.
